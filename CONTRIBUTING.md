# Contributing

1. Read README.md, AGENTS.md, and relevant docs.
2. Keep requirements, contracts, examples, implementation, and tests traceable.
3. Document compatibility impact and migration guidance.
4. Add automated tests for behavior and schema changes.
5. Never commit secrets, private ecosystem material, or unlicensed third-party content.
6. Describe validation performed and known limitations in pull requests.

The master registry is authoritative for ecosystem inventory and dependency metadata; this repository is authoritative for its own implementation.
